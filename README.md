# 山区小流域坡面治理措施布设与工程量核算系统

面向县水土保持站的三端协同工具：技术员在测绘成果上勾绘小流域与地类图斑、按坡度分级统计面积、依据地类获取措施建议；从措施库拖入措施并沿等高线吸附对齐，填写埂高、坑径、株行距等参数，系统按图斑面积自动核算土方量、苗木数与沟渠长度；方案提交后进入待复核，复核工程师逐图斑写意见并可整体退回，意见挂在对应版本上；站长端汇总各小流域治理面积、工程量与复核通过率，并按小流域与措施类型导出工程量清单与平面图。

技术栈：React 19 + Canvas2D（无地图库、无第三方 UI 框架），Vite 构建。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产出 dist/
npm run preview
```

首次打开会自动载入演示数据（青山沟、柳树沟两个小流域，11 个图斑、14 项措施、3 个历史版本）。
数据保存在浏览器 localStorage，右上角「重置演示数据」可恢复初始状态。

## 关键实现

### 测绘成果 → DEM → 坡度分级
`src/lib/dem.js`
- 解析等高线（每条线带高程）与高程点，按 8 m 格网做 IDW 插值（取最近 8 个样本、按距离反比加权），3×3 加权平滑两遍去除插值噪声。
- 用 Horn 三阶差分算坡度，按 `<5° / 5–15° / 15–25° / >25°` 四档分级。
- 统计某图斑面积占比时按格网中心落入判断并乘格网面积，同时用多边形解析面积折算，避免边界锯齿导致占比失真。

### 等高线吸附
`src/lib/snap.js`
- 等高线按 64 m 网格分桶建线段索引；鼠标位置查询半径内最近线段，返回吸附点、该等高线高程与切向角。
- 布设面状措施时，矩形长轴取该点等高线切向角，因此「沿等高线吸附对齐」是真的等高线走向，不是固定角度；按住 Shift 可脱离吸附自由旋转。
- 截水沟直接截取等高线的一段作为沟线；谷坊吸附到最近沟道并记录桩号 s。

### 工程量核算
`src/lib/measures.js`
- 梯田：田埂长 = 布设面积 ÷ 田面宽；筑埂土方 = 田埂长 × 埂高 ×（埂顶宽 + 边坡 × 埂高）；护埂灌木 = 田埂长 ÷ 株距。
- 鱼鳞坑：坑数 = 布设面积 ÷（行距 × 株距）；单坑土方按 60% 有效容积；苗木 = 坑数 × 每坑株数。
- 谷坊：断面为梯形，土方 = 断面面积 × 沟道宽；同时按沟底比降计算允许最大间距 H/i。
- 截水沟：梯形断面 × 沟长。
- 水保林/植草：穴数、苗木、草籽用量。
- 面状措施的工程量按「措施范围 ∩ 所属图斑」的相交面积计算，超出图斑的部分不计入。

### 校核规则
`src/lib/validate.js`
- 梯田落在 >25° 坡面：按措施范围内坡度格网统计，平均坡度 > 25° 或 >25° 面积占比 > 35% 判为错误，标红并提示改退耕还林（可一键转换）。
- 措施范围重叠：面-面用相交采样计算重叠面积，点-面判断包含，点-点按最小间距，线-线判断交叉。
- 谷坊间距：按所在沟道局部比降与谷坊高算允许间距，小于允许间距即拦截；布设谷坊时也会预先校验，不满足直接拒绝落点。
- 另有图斑未布设措施、措施超出图斑、图斑超出测绘范围等提醒。

### 版本与复核
`src/state/store.js`
- 提交复核时把措施与图斑完整快照存入版本对象，复核工程师看到的是提交那一刻的方案，技术员后续修改不会污染待复核内容。
- 版本记录 `submittedAt` / `reviewedAt` / `comments` / `overall`；退回或通过后状态落定，历史版本只读。
- 复核通过率 = 已通过版本数 ÷ 已审核版本数，站长端实时计算。

### 导出
`src/lib/planRender.js`
- 工程量清单 CSV（带 BOM，Excel 可直接打开）：小流域 × 措施类型 × 处数 / 面积 / 土方 / 苗木 / 沟渠，可再按小流域与措施类型筛选。
- 平面图 PNG：离屏 Canvas 绘制，含图框、图例、指北针、比例尺、标题栏（比例尺按 150 dpi 折算为 1:5000 一类标准分母），坡度底色、等高线、图斑、措施与编号。

## 测绘成果导入格式

在左侧「测绘成果 → 导入 / 更换」中支持：

1. 本系统 JSON（`{ contours: [{ level, points: [[x,y],…] }], spotHeights, channels }`）
2. GeoJSON：等高线为 `LineString`，要素属性含 `elevation`
3. CSV：`level,x1,y1,x2,y2,…` 每行一条等高线

`tools/gen-demo.mjs` 是演示数据的生成脚本（解析地形 → marching squares 抽等高线 → 写 `public/demo-survey.json`），仅用于造数，不参与运行时。
