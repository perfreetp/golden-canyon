# 神经电生理 · 头皮电极布点实训与考核系统

面向神经电生理科技师培训的 **国际 10-20 系统头皮电极导联布点** 实训与考核平台。
讲师端建课出题、人工复核；学员端在三维头模上完成布点、核对对称、查看扣分明细与错题回放；
后台维护头模分区词典、题库与班级名单；课程结束导出成绩表与错误率最高的前 5 个导联点。

## 技术栈

- **Svelte 5**（runes 响应式） + **Vite 8**
- **three.js r187** / **WebGL2**，全部几何由程序化数学曲面生成（无外部模型文件）
- 数据持久化：`localStorage`（单机演示，可导出 JSON 备份）

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产出 dist/
npm run preview
```

## 三维头模

`src/lib/headgeo.js` 用「水平截面扫掠 + 单调三次插值」构建头皮曲面：

- 半宽 `a(y)` / 前深 `f(y)` / 后深 `b(y)` 三条轮廓曲线生成连续可微曲面；
- 面部解剖（眉弓、眼窝、鼻梁、唇、颏、枕外粗隆）以法向起伏并入曲面本体，非贴片；
- 曲面为「星形」参数化，射线方向与表面点一一对应，因此投射、法线、投影可精确互解；
- `scalpMask()` 给出可贴电极区域（发际线以上、排除面部与耳廓），拖放越界会被拒绝。

`src/lib/montage.js` 用**角度域弹簧松弛**求解 21 个标准电极 + 双侧耳垂参考点：
弹簧目标长度取成人临床弦长，左右镜像作为硬约束，收敛后左右偏差 < 0.01 cm。

## 判分规则（四项各 25 分）

| 项目 | 判定 | 扣分 |
|------|------|------|
| 命名规则 | 字母前缀 + 编号；奇数=左、偶数=右；中线以 z 结尾不带数字 | 格式 5 / 侧别 4 / 重名 3 / 多余 2 |
| 分区归属 | 落点所属解剖分区与电极名前缀一致，且偏离标准标记位 ≤ 2.8 cm | 漏放 4 / 偏位 5 / 分区错 3 |
| 左右对称 | 同名左右电极镜像偏差 ≤ 1.5 cm；中线电极偏离正中线 ≤ 0.9 cm | 偏差 2–8 / 中线 5 / 无法核验 3–5 |
| 间距合规 | 任意两电极中心距 ≥ 1.5 cm | 每对 6；布点不完整时按完成度折算 |

总分按题目权重折算到 100 分。讲师复核可逐项改分并写评语，学员端实时可见。

## 目录

```
src/
  lib/
    headgeo.js      头皮曲面数学模型（截面轮廓、面部起伏、法线、投影、可贴区）
    montage.js      10-20 布点解算、命名解析、分区词典、相机预设
    grading.js      四项判分引擎、回放帧、TOP5 导联统计
    three-scene.js  three.js 构建（头模、电极、标签、分区贴图、面部细节）
    seed.js         课程 / 题目 / 班级初始数据
    demo.js         演示提交记录（确定性随机，走真实判分）
    store.js        localStorage 持久化 store
    export.js       CSV / JSON 导出
  components/
    ScalpCanvas.svelte   三维画布（拖放、选点、手柄、红框、对称叠加）
  views/            七个界面
```

> 演示数据为合成数据，仅用于教学演示；临床使用请以所在机构 SOP 与设备厂商手册为准。
