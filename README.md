# 消化内镜中心 · 平面图与运营排程系统

基于 **Vue 3 + Canvas2D + OffscreenCanvas** 的消化内镜中心分层平面图与运营排程演示系统。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run test:logic # 排程/数据逻辑冒烟测试（Node，无需浏览器）
```

## 平面图性能设计（2000+ 要素保持流畅）

- **离屏瓦片**：世界按 512px 切分，每个 `(缩放档 × 图层 × 瓦片)` 烘焙到一块 `OffscreenCanvas`，LRU 缓存（上限 260 块）。
- **视口裁剪**：每帧只计算并 `drawImage` 视口覆盖的瓦片，视口外要素零绘制。
- **局部坐标系**：瓦片渲染时 `translate(-tileOrigin)` 把世界坐标要素映射进瓦片，屏幕空间 `setTransform` 精确归位，无瓦片缝隙。
- **空间哈希命中**：260px 网格做点击命中检测，点选 O(1) 附近查找。
- **三档离散缩放**：小档仅房间轮廓 / 中档设备床位 / 大档编号与状态，低档主动减少绘制要素。
- **分层缓存**：建筑、设备、排程三层独立瓦片，开关图层不重建其它层；告警脉冲走主画布实时叠加，不触发瓦片重烘。
- **精准失效**：要素状态变化只丢弃其覆盖范围的瓦片；排程变化仅失效排程层。

## 自动排程规则（`src/scheduling/scheduler.js`）

1. **急诊优先**：加急预约在待排队列中最先处理，抢占当天最早可行时段。
2. **镜体周转**：镜体使用后进入 25 分钟洗消；调度器维护镜体时段占用表（检查档 + 1 周转档），周转未完成不重复派发。
3. **时段容量**：每档 30 分钟，房间并行数不超过护士长配置的容量。
4. **医师约束**：技能匹配 + 班次时段 + 同一时段不可重复排程。
5. **加急配额**：普通预约自动避开加急比例未达标房间的早期时段，为急诊预留通道。
6. **硬冲突不强行落位**：容量满/医师重叠/无可用镜体时输出候选时段列表，由人工在弹窗中改期。

## 模拟时钟

顶栏可调速度（0.5×–4×）与暂停。时钟推进驱动预约状态机：
`scheduled → checkedin → inprogress → recovery → done`，并自动产生迟到（超 15 分钟）、
爽约（超 30 分钟）告警与镜体洗消/回库事件，平面图状态与看板统计实时联动。

## 目录结构

```
src/
├─ canvas/      layout.js(要素生成) draw.js(绘制) tiles.js(离屏瓦片) FloorCanvas.js(视口控制器)
├─ scheduling/  scheduler.js(排程引擎)
├─ data/        mock.js(确定性演示数据)
├─ store/       store.js(全局状态/时钟/审计) stats.js(看板统计)
├─ views/       10 个界面组件
└─ utils/       随机数/时间槽/格式化
```

所有演示数据由固定种子确定性生成，刷新后布局与数据一致。
