# 藏臻馆 · 手办藏品展柜陈列与养护档案系统

基于 **Svelte 5（runes）+ SVG + D3** 的手办馆藏全流程管理系统，覆盖藏品建档、展柜陈列设计、紫外线核算、90 天养护、借展单据流转与损伤留档。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建
npm test           # 规则引擎单元测试（node:test，8 项）
node tests/e2e.smoke.mjs   # 端到端冒烟测试（Playwright，25 项，需先启动 dev）
```

首次使用点击侧栏「载入演示数据」，生成含承重超限、间距冲突、UV 超标、借展超期、养护逾期的完整场景。

## 功能与规则对照

| 需求 | 实现 |
| --- | --- |
| 藏品档案：比例/材质/入手价/瑕疵/盒位 | 「藏品档案」CRUD，含照片、瑕疵部位与程度、包装盒存放位 |
| 展柜立面拖拽摆位 | 「展陈设计」SVG 立面图 + d3-drag，从待陈列区拖入、柜内拖动换位、撤下 |
| 按 1:7 换算真实高度 | `figureHeightMm`：实物高度优先，否则 真实身高 ÷ 比例分母；立面图按 mm 等比绘制 |
| 层板承重超限当场提示 | 同层板重量合计 > 层板上限 → 红色冲突卡 + 负荷条变红 |
| 相邻间距 < 30mm 标出冲突两件 | 按 x 排序逐对核算，红色虚线框两件 + 立面图双箭头尺寸标注 |
| 灯光角度/时长累计紫外线 | 日剂量 = 时长 × cos(入射角) × 强度；累计 = 日剂量 × 陈列天数 |
| 超阈值换位建议 | 按材质 UV 耐受阈值（可在设置调整），超标即给换位/降时长建议 + D3 柱状图对比 |
| 90 天养护计划 | 除尘每 90 天到期，14 天后配套清洁；完成自动排下一周期，逾期看板汇总 |
| 借展单据流转 | 待出库 → 在展 → 归还验收中 → 已归还，支持回退 |
| 超期 3 天标黄推送 | 超宽限 3 天自动黄卡 + 通知中心推送（每单只推一次），每小时重扫 |
| 损伤登记点选部位 + 拍照 | 归还验收中/已归还可登记：SVG 图上点选（归一化坐标）、多照片压缩留档，回写瑕疵档案 |
| 馆长看板 | 在展数量、超期未还、养护逾期 KPI + D3 环形图 + 待办预警 |
| 导出借展交接单 | 可打印 HTML（含明细、既有瑕疵、损伤登记、签字栏），浏览器另存 PDF |

## 目录结构

```
src/
├─ lib/
│  ├─ rules.js          # 规则引擎纯函数（承重/间距/UV/养护/超期），可单测
│  ├─ store.svelte.js   # runes 全局状态 + localStorage 持久化
│  ├─ d3drag.js         # d3-drag 的 Svelte action 封装
│  ├─ handover.js       # 交接单 HTML 生成
│  ├─ photo.js          # 图片压缩 → dataURL
│  ├─ seed.js           # 演示数据
│  └─ utils.js          # 日期/比例/下载工具
├─ components/          # 表单、模态框、D3 图表、损伤点选、灯光角度
└─ views/               # 看板/档案/展陈/灯光/养护/借展/设置
tests/
├─ rules.test.js        # 8 项单元测试
└─ e2e.smoke.mjs        # 25 项 Playwright 端到端
```

## 数据存储

全部数据保存在浏览器 `localStorage`（键 `fca-store-v1`），照片经 Canvas 压缩为 JPEG dataURL。设置页支持 JSON 全量导出/导入与清空。
