# 山区输电线路路径选择与档距校核系统

SolidJS + Canvas2D 实现，面向电力设计院线路设计员与复核员的方案比选与校核工具。

## 运行

```bash
npm install
npm run dev      # 开发（默认 http://127.0.0.1:5173）
npm run build    # 生产构建到 dist/
```

## 四个界面

1. **路径规划**：等高线地形图（marching squares 实时生成）上布塔位。拖动塔位比选；点击档线中点圆点插塔；双击塔位删除；点击空白在末端加塔。三套方案 A/B/C 切换比选，实时显示造价估算、占地亩数、砍伐株数、红线重叠长度；坡度＞30° 塔位给出施工便道与弃土风险提示。
2. **纵断面校核**：自动切出沿线纵断面（地面线、塔位、导线弧垂抛物线、最小对地点），逐档表列出档距、高差、弧垂、最小对地距离；档距＞800m 或对地＜7m 整档标红；林木段给出砍伐宽度（走廊宽+2 倍树高）与株数统计；标注生态红线穿越长度。
3. **复核**：复核员逐档填「通过/退回」与校核意见；全部通过方可审定，存在退回档则退回设计员。退回后设计员在规划/校核界面看到逐档意见，改动过的档以橙色虚线/角标标识。
4. **审定输出**：方案审定通过后开放，生成塔位明细表（含里程、高程、坡度、便道难度、弃土风险、占地）、造价与占地汇总、生态红线重叠区段清单、施工交底图（平面图+纵断面+图签），可导出 CSV。

## 弧垂模板

按电压等级（110/220/500kV）× 气象条件（最高气温/覆冰/大风）套用不同弧垂系数 K，弧垂按抛物线公式 f = K·L² 计算，对地距离沿档 60 点采样取最小值。

## 状态流

草稿 →（提交复核）→ 待复核 →（审定通过）→ 已审定；待复核/已审定状态锁定塔位与模板编辑，退回后回到草稿可继续修改。方案数据持久化在 localStorage。
