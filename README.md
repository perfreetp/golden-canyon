# 童行 · 康复大厅互动训练展项布置与运营系统

面向儿童康复中心「康复大厅」的互动训练展项布置与运营系统。治疗师在后台平面图上摆放展项，
患者在展项大屏上玩训练小游戏，主管看运营数据；五个业务模块加一个患者终端。

技术栈：React 19 + TypeScript + Zustand + PixiJS 8（平面图编辑器与训练小游戏均为 PixiJS 实时渲染）+ Vite。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 产物构建
npm run preview    # 预览构建产物
```

## 五个模块

**1. 展项布置**（PixiJS 平面图编辑器）
- 设备库六类展项：轨迹追踪屏、平衡踏板、抓握训练台、认知配对桌、动作捕捉摄像头、定向音响。
  可拖拽入图，也可单击自动落在最近的空位；触屏下长按拖动同样可用。
- 选中后可拖动移动、顶部圆柄旋转（15° 步进）、四角手柄等比缩放，全部实时生效。
- 移动/旋转/缩放全程做碰撞检测：与其他展项重叠时整块标红、落位被阻止并退回上一有效位置。
- 靠墙展项靠近墙面时自动吸附并对齐墙面法线；地面展项吸附 0.5m 网格。
- 每个展项可填写训练部位（8 类）、适用年龄、单次时长、难度档位、每日场次上限。
- 右侧面板实时显示承重分区负载，预置展厅 24×16m、吊顶 3.6m、5 个承重分区与 10 处配电点。

**2. 内容配置**：为展项绑定训练小游戏（7 款，按设备类型过滤），设定达标阈值、时长、年龄与每日上限；
右侧实时显示「开放条件」核对表与小游戏预览。

**3. 发布审查**：待审核 / 已退回 / 已发布三个队列 + 审核流水。审核弹窗内展示内容配置、
适用患者校验、平面布局与安全校验；通过后患者端立刻开放，退回必须填写原因并通知提交人重新提交。

**4. 训练记录**：按患者 / 展项 / 日期三种维度汇总场次、达标场次、达标率、均分与时长，
支持 7/14/30 天、患者与展项筛选、关键字搜索，行内可下钻查看逐场明细与每日达标走势。

**5. 物料清单**：设备数量、屏幕尺寸、外形尺寸、功率、线缆长度估算与安装点位坐标；
可按设备展开点位明细，导出俯视图 PNG（2 倍分辨率，含网格、分区、配电点、编号与坐标）
与物料清单 CSV（含点位明细表），支持打印。

**运营看板**（审核人 / 主管）：各展项使用率（近 7 日场次 / 容量）、热门提示、患者活跃度、
排队情况（按展项分组、预计等待）、承重分区负载与超限告警。

**患者训练端**：只轮播「已发布」展项（随机顺序、6 秒切换），校验患者年龄是否匹配、
当日场次是否达上限；训练满设定时长自动结束并生成训练小结（得分、达标线、有效次数、星级与建议），
记录同步进训练记录与运营看板。

## 判定与计算规则

- 网格吸附：地面展项 x/z 取 0.5m 整数倍；墙面展项在距墙 ≤0.9m 时贴合墙面（留 5cm 安装缝）并对齐法线。
- 碰撞：旋转矩形之间的分离轴检测（OBB），不是简单包围盒；重叠时阻止落位。
- 承重：按展项中心点所属分区累加设备重量，超过分区上限在平面图与侧栏标红告警。
- 线缆：展项中心到最近配电点的水平距离 + 垂直落线（墙面按挂高−0.3m，落地 1.0m）+ 0.8m 余量，×1.15 安全系数，按 0.5m 向上取整。
- 达标：小游戏实时指标（命中率 / 稳定保持率 / 有效抓握率 / 配对正确率 / 动作同步率 / 节拍准确率）≥ 展项阈值。
- 训练记录：完成场次 = 实际训练时长 ≥ 计划 95%；提前结束记入记录但不计完成。
