# 岐黄导引 · 中医导引课程动画制作与治未病中心运营系统

基于 **SolidJS + SVG + D3.js** 的纯前端系统，覆盖「拆件绑定 → 关键帧动画 → 导出入库 → 组课 → 审查上架 → 学员练习反馈 → 运营看板」全链路。数据保存在浏览器 `localStorage`，无需后端即可完整演示。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 类型检查通过后的生产构建
npm run typecheck
```

## 五大角色与功能

### 1. 动画师工作台（`src/views/AnimatorView.tsx`）
- **拆件图层**：14 个部件（头、躯干，左右上臂/前臂/手、大腿/小腿/脚）。支持上传 PNG 分层图（FileReader → dataURL），未上传时用矢量人形占位；每部件可调蒙皮权重（0 不跟随骨骼 → 1 完全跟随）、偏移与尺寸。
- **骨架绑定**（`src/rig/`）：16 关节人形骨架，在 SVG 画布上拖动关节调整静止位置；双击空白新增自定义关节、双击自定义关节删除。部件按骨骼锚点 + 权重插值旋转。
- **关键帧与时间轴**（`Timeline.tsx`，D3 驱动）：菱形关键帧可拖动改时间、双击删除；播放头点击寻址。
- **逐段插值曲线**（`EaseEditor.tsx`）：每两个关键帧之间可独立设为**线性 / 缓入缓出 / 手动贝塞尔**，贝塞尔两个手柄可拖拽（二分法由 x 求 y，见 `util/math.ts`）。
- **呼吸节奏标记**：吸气/屏息/呼气秒数可配（默认吸 4s 呼 6s），时间轴按周期着色（蓝=吸、灰=屏、绿=呼）。
- **预览**：0.25x / 0.5x / 1x 倍速、循环开关，rAF 全局时钟（`hooks/useAnimationClock.ts`）。
- **导出**（`rig/exportFrames.ts`）：离屏 SVG → canvas 逐帧渲染，下载 PNG 序列帧 + 网格精灵图（含 atlas 元数据），动作自动登记进课程库。

### 2. 课程策划后台（`PlannerView.tsx`）
把课程库动作组合成课，配章节、每章时长、适用人群、每周练次；可存草稿或提交审查；被驳回的课带驳回意见展示，修改后可重新提交。

### 3. 审查台（`ReviewerView.tsx`）
逐条审查待审课程，可展开动作明细（实时播放 + 呼吸配比）；**驳回必须填写意见**，通过后课程才变为「已上架」；全部通过/驳回记录留痕（审查人、意见、时间）。

### 4. 学员端（`StudentView.tsx`）
仅展示已上架课程；按周一至周日的周计划卡片播放动作；练习后提交不适部位（14 部位下拉）与文字说明，反馈进入运营汇总。

### 5. 运营看板（`OpsView.tsx`，D3 图表）
KPI：练习总人次、**完课率**、**复练率**、平均**中途退出时间点**；图表含完课率月度趋势折线、各课程/教练人次柱状、退出点 30 秒分桶分布、学员不适部位汇总；支持按**课程、教练、月份**三维筛选联动。

## 核心目录

```
src/
├─ types.ts                 # 全部领域模型
├─ util/math.ts             # 插值/贝塞尔缓动/角度工具
├─ rig/
│  ├─ skeleton.ts           # 默认关节、骨骼、14 部件定义
│  ├─ kinematics.ts         # 正向运动学、关键帧采样、角度插值
│  ├─ figureMath.ts         # 部件位姿（锚点 + 权重）
│  └─ exportFrames.ts       # PNG 序列帧 / 精灵图导出
├─ render/staticMarkup.ts   # 离屏 SVG 字符串渲染
├─ components/              # Figure / RigStage / Timeline / EaseEditor ...
├─ views/                   # 五个角色视图
└─ store/store.ts           # Solid Store + localStorage 持久化 + 种子数据
```

## 设计要点

- **运动学**：关键帧存每个关节的世界角与根节点位移；运行时正向运动学按静止骨长逐级求坐标；角度插值走最短弧。
- **权重蒙皮**：部件旋转角 = `lerp(静止角, 当前骨骼角, weight)`，权重 0 的部件保持静止朝向。
- **持久化**：Solid Store 变更后防抖写入 `localStorage`；顶栏可一键重置为演示种子数据。

## 测试

```bash
npm run test:math     # 12 项数学/运动学单测（esbuild 转译后在 Node 运行）
npm run test:e2e      # 13 项端到端：驱动系统自带 Edge 遍历五角色完整业务流
npm run test:export   # 真实导出 80 帧 PNG + 精灵图并校验入库（需先 npm run dev）
```

端到端用 `playwright-core` 连接本机 Edge（不下载浏览器）。e2e 覆盖：图层计数、0.25x 循环播放、呼吸色带、逐段缓动切换、打关键帧、建课提交、驳回（含意见校验）→重提→通过上架、周计划 7 天、不适反馈、KPI/D3 图表渲染、三维筛选、持久化。
