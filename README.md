# 手办涂装分色与打样审批系统

Vue 3 + 原生 WebGL2 实现的手办涂装分色、打样审批与车间下发系统。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 四个界面

| 路由 | 界面 | 功能 |
|---|---|---|
| `/#/paint` | 涂装分色台 | 导入素体模型生成打样单;WebGL2 素体(头雕/躯干/披风/底座)点击选区,绑定漆号、光泽度、喷涂遍数;漏涂/空漆号自动标红(列表+3D 脉冲高亮),校验通过才能提交 |
| `/#/qc` | 品控审批 | 标准色卡与样件实拍色并排对比,ΔE(CIE76)>3 的区域自动生成超差清单;退回必须填原因并计入返工次数;V1/V2… 按钮切换修改前后版本对照 |
| `/#/dashboard` | 主管看板 | 按批次统计通过率、返工次数、平均返工;超期打样单清单与返工排行 |
| `/#/workshop` | 车间分色表 | 仅显示「通过」单的分色表与漆号用量清单(区域系数×遍数),一键导出 CSV 给喷涂组长 |

## 状态机

```
待分色 → 分色中 → 待审批 → 通过
                     └→ 退回(返工次数+1,需填原因)→ 修改后重新提交
```

## 技术要点

- `src/webgl/figurine.js`:原生 WebGL2 渲染器 —— 程序化生成头雕(球)/躯干(车削)/披风(开口锥壳)/底座(圆柱),Blinn-Phong + Fresnel 着色,光泽度映射高光指数;离屏 ID 帧缓冲实现点击拾取
- `src/data/paints.js`:漆号标准色卡库、RGB→Lab 转换与 CIE76 色差;样件实拍色用确定性伪随机模拟(返工次数越多扰动越小,体现工艺收敛)
- `src/store.js`:全局响应式 store,localStorage 持久化,内置多批次种子数据(含超期单、返工单、已通过单)
