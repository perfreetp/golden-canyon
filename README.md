# 山区地质灾害隐患点三维判读与巡查工单系统

基于 **Vue 3 + three.js** 的零构建纯静态单页应用，面向县地质灾害防治办公室的群测群防业务：
调查员在带等高线的三维地形上圈定滑坡/崩塌隐患点并录入参数，系统自动计算风险等级与红色复核预警，
审核员退回补证或确认派单，乡镇巡查员按周期打卡上报，县办通过看板汇总并导出台账与撤离明白卡。

## 快速开始

```bash
# 方式一：零依赖静态服务器（推荐）
node tests/serve.js          # 然后浏览器打开 http://localhost:8731/
# 或 npm run serve

# 方式二：任意静态服务器
python -m http.server 8731
```

> 直接双击 `index.html` 也可运行（CDN 加载 Vue/three/ECharts，需联网）。
> 数据保存在浏览器 `localStorage`，顶栏「重置演示」可恢复内置演示数据。

## 五个业务界面

| # | 界面 | 核心能力 |
|---|------|----------|
| 1 | **三维判读** | 程序化山地地形、等高线（10m 细/50m 粗）、高程/坡度双渲染、D8 汇水线、多边形圈定、民房布放、隐患点列表与定位 |
| 2 | **审核工单** | 待办/已办工单、隐患全档案、红色复核审查、退回补证、确认并生成 7/15 天巡查任务、销号 |
| 3 | **巡查打卡** | 周期任务卡片、逾期标红、裂缝/警示牌上报、新增裂缝强制附照片并自动触发复核 |
| 4 | **汇总看板** | 5 项 KPI、分乡镇柱状图、风险等级环形图、乡镇统计表（隐患数/威胁人数/逾期数） |
| 5 | **台账明白卡** | 群测群防台账表格、CSV 导出、逐点生成可打印的地质灾害避险撤离明白卡 |

## 业务规则

- **自动风险评级**：按坡度、汇水面积、威胁户数、岩土类型综合评分 → 一般 / 低 / 中 / 高风险。
- **红色复核预警**：实测坡度 **>35°** 且坡体下方 **10m 内有民房** 时自动标红，三维场景红色脉冲警示，
  调查员须现场复核确认后方可提交审核（系统强制拦截）。
- **状态机**：待核查 → 待审核 →（已退回 ↔ 补证重提）→ 已确认 →（待复核 ↔ 复核结论）→ 已销号。
- **每次变更**均记录操作人和时间，形成完整时间线追溯。
- **三种角色**：调查员（王调查）、审核员（李审核）、乡镇巡查员（张巡查），顶栏切换，界面按角色显隐操作。

E2E 覆盖的真实业务闭环：
红色未复核提交拦截 → 现场复核确认 → 审核退回 → 缺材料重提拦截 → 补照片/撤离路线后重提 →
审核通过派单（7 天）→ 巡查打卡 → 无照片新增裂缝被拦截 → 真实文件上传照片 → 新增裂缝自动转待复核 → 历史追溯。

## 关键技术点

- **程序化地形**：fbm 值噪声 + 三角函数叠加生成 600m×600m 山地，170 段网格顶点着色。
- **D8 汇水累积**：100×100 网格按最大坡降确定流向，高程降序传播累积量，阈值提取汇水线并计算流域面积。
- **等高线**：120 格规则网格 marching squares 等值线提取，10m/50m 分级。
- **坡下民房预警**：坡度阈值 + 坡向下方判定（房屋高程 ≤ 坡体均值）+ 点到多边形距离 ≤10m 三重条件。
- **响应式数据层**：`store.state` 经 `reactive()` 包装后回注 store，保证 store 内部原地变更与视图依赖追踪同源。
- **零构建**：全部使用 UMD/全局构建 CDN，无打包步骤，便于离线部署到政务内网（可将 CDN 资源下载到本地替换）。
