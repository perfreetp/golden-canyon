# 关节校核台 · Figure Joint QA

面向手办/可动人偶的三方协同校核系统：结构工程师标定关节，原型师摆姿势试配件，品控主管审核放行。
基于 React + TypeScript + three.js，几何与干涉判定全部在浏览器内实时计算。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出 dist/
```

## 五个工作区

| 页面 | 使用角色 | 做什么 |
| --- | --- | --- |
| 校核总览 | 三个角色 | 待校核 / 已退回 / 已放行数量、放行率、待办队列、失效提示、操作留痕 |
| 模型关节配置 | 结构工程师 | 导入分件模型，逐件标定关节为球关节或铰链，设定旋转轴向与角度上下限 |
| 姿势测试台 | 原型师 | 拖拽关节手柄摆姿，实时穿插检测与红色标注，保存姿势快照，提交校核单 |
| 配件库 | 原型师 | 手型 / 武器 / 底座替换件，装配后自动复核接口，配件改版触发结果失效 |
| 校核任务 | 品控主管 | 逐项查看角度余量与干涉记录，填写意见退回，或通过并锁定版本 |
| 放行报告 | 三个角色 | 由审核通过生成、不可编辑的放行文件，配件改版后自动标注失效 |

## 核心判定规则

- **穿插判据**：相邻分件以胶囊体代理，两胶囊最小间隙为负即穿透；穿透深度 > **0.3 mm** 判为超限，
  界面上把两个部件标红并给出两个部件名称与深度。同关节装配件、模型登记的贴合接缝、
  以及配件"坐实"的配合面（手型套腕、武器插握把、底座承脚）不参与穿插判定。
- **角度余量**：单向范围（如肘 0–120°、膝 0–95°）的静止位在下限，只把远端边界计入余量；
  余量 < 8° 交给品控判断，不回退提交。
- **接口复核**：接口形式、配合直径（含公差）、嵌合深度三项逐条比对，武器插入手型提供的握把接口。
- **失效联动**：配件改版 → 引用它的校核单与放行报告全部作废，标注改版前后版本号与时间。
- **留痕**：每次标定、装配、提交、退回、放行、失效都记录操作人、身份与时间。

## 代码结构

```
src/engine/      纯计算层（无 DOM）
  math.ts        向量/四元数、线段最短距离、胶囊穿透
  rig.ts         关节树、正向运动学、碰撞对筛选
  assembly.ts    配件装配求解与接口复核
  evaluate.ts    校核汇总：余量、干涉、接口、放行判定
src/data/        示例人偶分件、配件库、演示校核单
src/components/  Viewport（three.js 场景）、通用 UI
src/pages/       五个工作区
src/store.ts     zustand：状态、业务规则、审计日志
```

模型数据用胶囊体代理分件几何；接入真实 FBX/STEP 时，把 `FigureModel.parts` 换成三角网格并以
BVH/SAT 求最小穿透即可，`evaluate.ts` 之上的判定与流程无需改动。
