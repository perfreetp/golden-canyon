# 消化内镜图文报告 · 分段示意图生成与质检平台

面向消化内镜中心报告组与复核员的单页应用。按检查参数确定性地生成食管 / 胃 / 十二指肠
分段示意图，支持手工微调病灶标记与标注框，并提供四级自动质检、逐条复核、批次放行与
历史归档检索。

技术栈：Svelte 5（runes）+ SVG + D3（contours / drag / geo 变换）。

## 启动

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # 生产构建到 dist/
npm test             # 纯领域逻辑测试（33 项）
npm run test:e2e     # 浏览器端到端测试（33 项，需本机 Chrome）
```

端到端测试默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`，
可用 `CHROME_PATH` 覆盖。

## 核心流程

```
批量导入 / 新建批次
        │
        ▼
报告工作台（报告组）          生成示意图 + 自动质检
  · 检查参数组 + 种子 → 确定性布局
  · 拖动病灶标记、标注框；改尺寸；改正文
  · 同一参数组下「重新生成」保留全部手工调整
        │  提交复核
        ▼
复核台（复核员）              逐条确认 / 驳回
  · 确认：该条目通过
  · 驳回：整例退回「待整改」，报告组修改后重新提交
        │  整例签名
        ▼
批次总览                      放行门禁
  · 全部已签名 → 生成批次清单（例数 / 问题分布 / 复核人 / 签名码）
        │
        ▼
历史归档                      按检查日期、操作医生、关键词检索已放行批次
```

一个批次只有在**每一例都已复核签名**时才允许放行；草稿、待复核未处理完、被驳回退回
的病例都会作为阻塞项列在「批次放行」卡片里。

## 确定性生成

一例报告的分段图与正文都是 `参数组 + 种子` 的纯函数：

- `generationKey(params)` 由检查类型、内镜型号、图像模式、体位、注气量、操作医生、
  报告医生与种子拼成。
- 病灶数量、性质、尺寸、落点由 `mulberry32(hash32(key))` 抽样，并在管腔内做安全边距
  采样，保证标记不越界。
- 黏膜纹理由同一键派生的噪声场经 `d3.contours` 生成等值线，叠加按部位生成的皱襞
  几何（胃的皱襞垂直于贲门—幽门轴向、食管的纵行条纹、十二指肠的环状襞）。

因此**同一参数组 + 同一种子**在任何机器、任何时间都得到完全一致的病灶位置与纹理；
换种子则重新抽样。

## 手工调整的保留规则

局部修改记录在 `case.manual`，包含三类：

| 类型 | 存储 | 何时保留 |
| --- | --- | --- |
| 病灶标记位置 | `manual.lesions[id] = {x, y, manualPos}` | 参数组与种子不变 |
| 病灶尺寸 | `manual.lesions[id] = {longCm, shortCm, manualSize}` | 参数组与种子不变 |
| 标注框位置 | `manual.annotations[id] = {x, y, manual}` | 参数组与种子不变 |
| 正文文本 | `manual.text` | 参数组与种子不变 |

`regenerateContent()` 对比生成前后 `generationKey`：相同则逐项叠加手工值并在界面提示
「保留 N 处手工调整」；不同（换参数或换种子）则清空微调并提示「已随本次重绘清空」——
因为旧的手工坐标不再描述新布局。关闭再开启某个部位同样会重新生成该部位内容，并保留
其手工调整。

## 自动质检

| 检查项 | 判定 | 默认级别 |
| --- | --- | --- |
| 缺部位 | 检查类型要求的部位未生成，或正文描述了该部位但图缺失 | 严重 |
| 标记超界 | 标记中心落在管腔轮廓外，或标记圆半径越出管壁 / 图幅 | 严重 |
| 标注文字重叠 | 同一部位两个标注框重叠面积 ≥ 较小框的 3%（≥45% 升为严重） | 一般 |
| 病灶尺寸与正文不一致 | 正文中同部位第 n 个尺寸与图中第 n 个标记相差 > 0.08cm（≥0.4cm 或相对偏差 ≥25% 升为严重） | 一般 |
| 标注文字溢出 | 估算文本行宽超标注框宽度 | 提示 |
| 标注框越界 | 标注框超出 320×384 图幅 | 提示 |
| 标注遮挡病灶 | 标注框盖住了它所标注的病灶标记 | 一般 |

严重 / 一般 / 提示三级用颜色区分；每条发现都带「应为 / 实际 / 部位 / 标记 ID」，复核
员可点选直接高亮对应标记。发现项 id 由检查类型 + 部位 + 关联标记 + 关键字段哈希得到，
因此在内容不变的重算中保持稳定，已确认的判定不会丢失。

## 目录

```
src/
  lib/
    prng.js        FNV-1a 哈希与 mulberry32 确定性随机
    geometry.js    样条、管状多边形、点包含、重叠面积
    anatomy.js     三个部位的轮廓/管腔/分区/地标、参数枚举
    texture.js     d3.contours 黏膜纹理与皱襞几何（带缓存）
    lesions.js     确定性病灶布局、标注框避让、正文生成
    qc.js          自动质检引擎与叙述解析
    model.js       病例/批次领域模型、状态机、放行门禁、批次清单
    demo.js        演示数据（一个进行中批次 + 两个已放行批次）
    store.svelte.js  Svelte 5 runes 状态容器
  components/      DiagramPanel（SVG 面板）、图标、级别/状态徽标
  views/           Workbench / Review / Batch / Archive / Import
tests/
  domain.test.js   领域逻辑单测
  ui.e2e.mjs       浏览器端到端测试
```
