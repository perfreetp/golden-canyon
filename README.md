# 心脏超声切面示意图 · 参数化生成与批次质检系统

Vue 3 + SVG + D3 实现的心脏超声培训中心素材生产与质检系统。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```

## 功能（四个页面）

| 页面 | 说明 |
|---|---|
| 批次管理 | 教研员录入切面类型、探头角度、腔室标注层级、线宽、配色规范、随机种子，创建素材批次；列表展示供应方、提交时间、复核人、放行结论 |
| 参数生成 | 按规则过程式生成腔室轮廓、瓣膜、血流方向、标注引线；拖动标注可手动微调并**自动锁定**，重新生成只重排未锁定部分；同参数+同种子输出完全一致 |
| 校验复核 | 自动检查：标注出界 / 腔室面积比例偏差>5pp / 文字重叠 / 缺失必要标注 / 引线交叉，按 严重·一般·提示 三级列出；复核员逐条确认或驳回并写意见；无确认的严重问题才允许放行，否则退回供应方并附问题清单 |
| 归档检索 | 按批次号、供应方检索历史批次，导出放行报告（HTML） |

## 角色（页眉切换）

- **教研员**：建批次、生成/重排、编辑锁定、跑检查、提交复核
- **复核员**：逐条确认/驳回问题、放行或退回
- **供应方**：只读查看本供应方批次与退回问题清单

## 关键设计

- `src/rng.js`：xmur3 + mulberry32 确定性随机数，种子 = `种子串::切面类型::序号`
- `src/generator.js`：纯函数生成器；`regenerateKeepingLocks` 通过确定性标注 id 保留锁定项
- `src/qc.js`：五项自动检查与放行判定（全部复核完毕且无已确认严重问题）
- `src/store.js`：响应式状态 + localStorage 持久化，内置 4 个演示批次（已放行/复核中/已退回/待生成）
- `.test/`：核心逻辑验证脚本（确定性、锁定保留、质检分布），可用 `npx esbuild .test/xxx.mjs --bundle --format=esm --outfile=.test/b.mjs && node .test/b.mjs` 运行
