# 神经影像断层解剖分层标注与考核平台

基于 **React 18 + PixiJS v8 + Vite** 的教学平台，覆盖断层序列导入、五类图层分层标注、LOD 流畅渲染、套索命题、自动评分、教师复核与成绩归档的完整闭环。

## 启动

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 生产构建
node scripts/smoke.mjs   # 数据生成与评分算法冒烟测试
```

右上角可切换三种角色（数据各自独立、持久化在浏览器 localStorage）：

| 角色 | 工作台 |
| --- | --- |
| 教学秘书 | 断层序列导入台、成绩与归档 |
| 教师 | 命题工作台、复核中心、成绩分析 |
| 学员 | 断层学习、考核任务 |

## 核心能力与实现要点

### 1. 断层序列与五类图层（`src/lib/data.js`）
- 确定性随机（mulberry32）生成 60 层轴位断层、**3400+ 个解剖要素**，每次导入结果一致。
- 五类图层：动脉、静脉、颅神经、功能区、病灶；每个要素带 `lod: low/high` 两级细节标记与预计算包围盒。
- 几何形态：走形线（血管/神经）、多边形区域（脑叶/水肿带）、椭圆（核团/病灶）。

### 2. PixiJS 高性能画布（`src/components/SliceCanvas.jsx`）
- **世界容器变换**：平移/缩放只改一个 Container 的 transform，不重建几何。
- **视口裁剪**：每帧按 `bboxesIntersect` 剔除视口外要素，渲染器尺寸即视口，画布外自然不可见。
- **两级 LOD**：低倍（scale < 1.35）只画脑叶轮廓与主要血管/神经/病灶主体；高倍铺开细小分支与神经走形。
- **批量绘制**：每图层一个 Graphics 对象，同层要素合并指令；拖拽时节流重建（120ms），保证数千要素流畅。
- 点选高亮（白色描边 + 名称标签）、滚轮以光标为锚点缩放、套索绘制、复核叠加（标准答案/超差参考区/多画区）。
- 渲染顺序：底图（颅骨/脑实质/脑室）→ 五图层 → 高亮 → 标签 → 套索 → 复核叠加。

### 3. 命题与考核流转（`src/views/TeacherWorkbench.jsx`、`ExamView.jsx`）
- 教师在套索模式下圈出目标结构，设定题干、所属图层、**允许偏差半径（6–48）与分值**，组卷并指派学员组、截止时间。
- 任务状态机：**草稿 → 已发布 → 进行中 → 待复核 → 已归档**，每次流转记录操作人与时间（任务级审计 + 全局审计时间线）。
- 学员进入答题后图层强制锁定为题干允许的几层，题目自动跳转命题层号。

### 4. 自动评分（`src/lib/geometry.js`）
- 学员圈画与标准答案分别栅格化（4 单位/格），标准答案按容差半径做形态学膨胀。
- 输出覆盖率（召回）、容差内精确率、IoU，按 0.6/0.4 加权折算分值。
- 超差/漏画区域与多画区域通过连通域提取为参考多边形，在画布上以红/黄标记回看。

### 5. 复核与归档（`ReviewView.jsx`、`ReportsView.jsx`）
- 教师逐题改分、写评语，可恢复机评分；全部复核后答卷标记完成。
- 成绩单、按结构错误率排名的错题汇总，支持导出 UTF-8 CSV（Excel/WPS 直接打开）供教学秘书归档。

## 目录结构

```
src/
├─ lib/
│  ├─ data.js       # 断层序列与解剖要素生成
│  ├─ geometry.js   # 几何、栅格化、膨胀、自动评分
│  ├─ rng.js        # 确定性随机
│  ├─ storage.js    # localStorage 持久化
│  └─ store.jsx     # Context+Reducer、任务流转、审计
├─ components/      # SliceCanvas、图层面板、要素侧栏等
└─ views/           # 六个角色工作台视图
scripts/            # 冒烟测试与无头浏览器验证脚本
```

> 演示数据全部为程序生成的教学示意结构，不对应真实患者影像。
