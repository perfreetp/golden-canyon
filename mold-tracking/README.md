# 模塑云跟单 · 手办代工厂模具与注塑批次跟单系统

SolidJS + three.js 单页应用，面向手办（潮玩）代工厂的模具全生命周期与注塑批次跟单。
纯前端实现，数据保存在浏览器 localStorage，内置一套演示数据，无需后端即可运行。

## 启动

```bash
npm install
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物
node e2e/smoke.mjs   # 端到端冒烟测试（需先 npm run dev，使用系统 Edge 无头浏览器）
```

## 角色

顶栏切换身份，数据视图随之隔离：

- **工艺员**：全部功能（工作台、款式与分件、试模管理、模具台账、批次跟单、车间看板）。
- **客户跟单**：只能查看自己客户名下款式的开模/试模进度、批次状态与不良率，看不到其他客户数据，也没有任何工艺操作入口。

## 功能与业务规则对照

| 需求 | 实现位置 / 规则 |
| --- | --- |
| 按分件建开模单，登记模号、穴数、材质、色号、寿命 30 万模次 | `款式与分件` → 建开模单（`store.createMoldOrder`），寿命默认 300000 可改，模号全局唯一校验 |
| three.js 分件装配示意 | `src/three/Assembly3D.tsx`，按分件几何体/颜色/位姿装配，可旋转缩放、点击分件联动高亮 |
| 模穴分布 | `src/three/CavityView.tsx`，按穴数方阵排布，俯视 3D + 穴号标签 |
| 试模缺陷（缩水/飞边/顶白等）点选到具体分件 | `试模管理` → 登记试模，在装配 3D 上点选或下拉选择分件 |
| 不带缺陷照片不能提交 | 每条缺陷必传照片（图片自动压缩为 JPEG dataURL），无照片无法添加缺陷、无法提交（`store.submitTrial`） |
| 不通过写修模方案后回到待试模 | 不通过时修模方案必填 → 分件转「修模中」且修模次数 +1；点「修模完成」回到「待试模」 |
| 修模次数累计到分件档案 | `Part.repairCount`，分件档案弹窗含试模/修模时间线、模穴视图与寿命 |
| 批次状态机 | 待排产 → 注塑中 → 待检验 → 放行 / 返工（返工完成回待检验复检） |
| 每打一模自动扣减寿命 | `store.addShot`：按模次扣减 `lifeUsed`，按穴数自动算出件数并累计良/不良，写入打模日志 |
| 剩余不足 10% 排产拦截 | `store.isMoldBlocked`，排产动作被拦截并提示开新模；新建批次下拉中红线模具直接禁用 |
| 客户只看自己款式进度和不良率 | `CustomerPortal`，按 `customerId` 过滤全部数据 |
| 车间看板按机台统计当日模次、不良率、超期批次 | `车间看板`（`pages/Board.tsx`），数据取自当日打模日志 |
| 导出批次检验单 / 模具台账 | 批次行「检验单」与模具台账页「导出台账 CSV」，UTF-8 BOM，Excel 直接打开 |

## 目录结构

```
src/
  types.ts            领域模型
  store.ts            SolidJS store + localStorage 持久化 + 全部业务规则/演示数据
  lib/utils.ts        日期、CSV 导出、图片压缩等工具
  three/
    Assembly3D.tsx    分件装配 3D（点选、缺陷高亮、自动旋转）
    CavityView.tsx    模穴分布 3D
    shape.ts          分件几何体工厂与穴数排布
  pages/
    Dashboard.tsx     工作台（预警总览）
    Styles.tsx        款式与分件（开模单、3D 装配、分件档案）
    Trials.tsx        试模管理（缺陷点选 + 照片强制 + 修模流转）
    Molds.tsx         模具台账（寿命、模穴、CSV 导出）
    Batches.tsx       批次跟单（状态机、打模扣寿命、检验、检验单导出）
    Board.tsx         车间看板
    CustomerPortal.tsx 客户跟单门户（数据隔离）
  ui.tsx              弹窗、状态徽章、寿命进度条等通用组件
e2e/smoke.mjs         22 项端到端冒烟测试
```

## 演示数据要点

- 模具 `M-A018-05`（右臂护甲）已用 28 万 / 30 万模次，剩余 6.7%，对其批次 `BN-261105` 排产会被拦截，可直接体验红线流程。
- 「左臂护甲」处于修模中（已修 3 次），可体验「修模完成 → 待试模 → 复检」。
- 顶栏「重置演示数据」可一键还原。
